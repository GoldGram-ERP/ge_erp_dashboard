## Open points for the owner

1. Expired session mid-form: a 401 `signInRequired` calls `leave()` (hard redirect to sign-in), so the form's data is lost and nothing says why. Needs a re-sign-in dialog over the form (like the session lock). Not built.
2. G3 rule 4 (no generic base classes, wrappers, option flags): the engine (`ThingPage`, `FormView`, `RecordSheet`, `Table`) is a configuration-driven wrapper; its configs are option bags (`when`, `confirm`, `toPayload`, `custom`). Limit: a page that does not fit the config escapes through `custom`, which skips the engine's guards (the double-submit ref, offline check), so each custom form repeats them. Decision: keep the engine as asked and move the guards into a shared hook, or accept the repetition.
3. `api()` now dedupes identical keyless writes by method+path+body: two intentionally identical actions started within one answer time are one request.
